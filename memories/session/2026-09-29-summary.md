# 会话小结 — 2026-09-29

主题：**按抽查报告第 6 节把判据修完 + 覆盖率口径改造**（清单里"马上能做完、不花钱"的那一批，全部零 LLM / 零网络）。

## 做了什么（11 处判据修复 + 1 处口径改造）

### BOM 类：不再"看名字猜身份"

1. `_check_dcdc_feedback_network`：去掉裸两字母 "MP/SY/MT/XL" → 位号必须是 IC 前缀 **且** 料号命中明确稳压器系列
   （原来 XL-1608(LED)、MPU6500、磁珠都被当"开关稳压器"去要 FB 分压电阻）。
2. `_check_mosfet_gate_resistor`：去掉裸 "SI/MOS/AO" → 位号 Q 前缀或明确型号前缀；
   并且让 `has_gate_r` **真正参与判断**（原来算出来没用，等价于"只要像 MOSFET 就报"）。
3. `_check_optocoupler_input_resistor`：去掉裸 "PS"（所有 TPS 电源芯片都被判光耦）；
   限流电阻改为"BOM 里存在电阻"，不再要求电阻位号前缀 == 光耦位号前缀（U vs R 恒不相等 → 有光耦必报）。
4. `_check_resistor_power_rating`：要求位号是电阻前缀（原来 LED 规格文本「功率:60mW」被当成功率电阻）。
5. `_check_battery_voltage_divider`：去掉裸 "BAT"（BAT54CT 肖特基二极管被当"电池供电系统"）。
6. `_check_analog_digital_separation`：新增 `_kw_hit()` 短词边界匹配（原来 "AD" 命中 PicoBlade → FPC 连接器被当模拟器件）。

### 走线 / 几何类

7. `_check_impedance_matching` **重写**：差分网络改用 `differential_impedance` + 差分目标
   （原来拿单端 microstrip 公式去比差分目标，结构性偏差、USB 网络必报）；
   按网络聚合去重（原来 `traces[:50]` 截断 + 逐条报）；排除电源/地；
   只判高速接口的差分组；对内间距按"对"缓存。
8. `_check_trace_acute_angles`：锐角加"焊盘入口几何"二次过滤（两腿 <0.5mm 且距焊盘/过孔 <1.0mm 跳过）；
   直角只对高速/时钟/差分网络报（原来 75/76 块板都响）。
9. `_check_crosstalk_spacing`：加网络类别门控（电源/地线对、按键/蜂鸣器/32kHz/GPIO 不套 3W 准则）；
   类别改为**段级预计算**——顺带把实验耗时从 347s 降回 58s。
10. `_check_diff_pair_spacing` / `_check_diff_pair_length`：新增 `_diff_groups_src()` 区分
    「工程 NET 规则声明的差分组」与「名字后缀猜出来的配对」——猜的配对不判间距、等长降级 INFO；
    等长门限由「0.5mm 一刀切」改为「≥2mm 或 ≥10% 组内平均长」；间距门限 3W → 4W（明显松耦合才报）。
11. `_check_stub_length`：要求 ≥4 层 **且** 同网络 ≥2 个过孔（二层板不存在 stub，原来抽样 5/5 全是误报）。
12. `_check_signal_traces`：绝对下限按层数（≥4 层取 0.09mm）；相对判据只对"同一网络内混用多种线宽"生效
    （整网统一选细 = 设计意图）。
13. `_check_capacitor_voltage_derating`：新增 `_extract_voltage_rating()`——电压必须是独立 token 且 ≥2.5V
    （原来料号 `…R0VH…` 被抓成「0V，裕量不足」）。
14. `_check_decoupling_proximity`：IC 判定改用统一元件分类（原来把"除电阻/电感外所有元件"当 IC，
    咪头/蜂鸣器/电池座全成了 IC）；判定改为「到**最近** IC 的距离」。

### 覆盖率口径（报告第 6 节第 5 条）
