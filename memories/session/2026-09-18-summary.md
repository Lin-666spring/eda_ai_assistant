# 会话小结 — 2026-09-18

主题：**激活长期失效的「走线锐角」规则**（审计待处理项第 1 条）。

## 做了什么

1. **新增 `src/pcb/geometry.py`**：把「无序 LINE 线段 → 有序折线 → 拐角内角」抽成可复用几何。
   - 端点串联：0.01mm 容差空间哈希 + 并查集归簇（不改解析器的 `segments` 模型）；
   - 去重：零长线段、同一对端点的重复 LINE 全丢弃；
   - 切折线：按图论度数在分叉/端点处断开，**只有度数为 2 的节点才可能是走线拐角**；
   - 转角：返回 `Corner(angle_deg, vertex, leg_in_mm, leg_out_mm)`，内角 180°=直行、135°=45°布线、90°=直角、<90°=锐角。
2. **重写 `_check_trace_acute_angles`**（旧判据 `t.has_sharp_angle` 无人设置，是死代码）：
   - 锐角（内角 <89°）→ WARNING「走线锐角检查」（酸陷阱 / √2 线宽阻抗突变）；
   - 直角（89~91°）→ INFO「走线直角检查」（SI 角部阻抗突变）；
   - 两侧腿 <0.05mm 的退化拐角（焊盘入口短桩）跳过；锐角排在直角前，输出顺序稳定。
3. **阈值进 `src/constants.py: PCBConstants`**，并给 `scripts/calibrate_trace_thresholds.py` 加了拐角
   统计段落，产出 `experiment_results/acute_angle_calibration/`（零 LLM / 零网络）。
4. **单测**：`tests/test_acute_angle.py`（20 项）—— 乱序/颠倒线段、重复线段、T 形节点、容差合并、
   闭合环、45°/直角/折返角度定义、最小腿长过滤、规则触发与严重度、真实 .epro2 冒烟。
5. **接好周边**：`design_scorer` 增加「走线直角」→ signal 维度映射；`review_agents` 的
   signal 审查师 focus_rules 补「走线直角」；`src/pcb/__init__.py` 导出几何函数。
6. **修 `scripts/epro2_rule_coverage.py` 的一个统计口径 bug**：一个规则函数产出多个 `rule_name` 时，

## 重要坑（写进 epro2-format.md）

- 同一 (网络,层) 的 LINE **不按路径顺序**记录（相邻线段端点相接率仅 7%~48%）——必须串联；
- **存在重复线段**（实测 1331 段里 77 段重复）——不去重会串出假 0° 折返，误报锐角。
