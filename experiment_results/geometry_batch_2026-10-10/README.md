# 几何批：板边真距离 / 元件间距重写 / 差分链路径（2026-10-10）

> 「11 条规则真实化」第三批（前两批：解析器批 747992a、标准表批 29b9766）。
> 台账 #17 尾巴（全网线段和）、#24（元件间距索引相邻 4 项）结案；
> 走线板边包围盒口径升级为轮廓多边形真距离。

## 改动

### 1. 解析器：板框从「包围盒」到「轮廓环」
- `board_outline["outline_rings_mm"]`：BOARD_OUTLINE 的 POLY 在文件里是
  多条独立描边（每条常只有一段线），把 ARC/CARC 按 10° 弦段离散化后
  chain_segments(0.05mm) 拼回环；开放链也是边界，一并保留。
  金样 72/78 板有真实板框（38 多边形 + 34 矩形，6 板铜包围盒兜底跳过）。
- `_polygon_points(_copper_ring_points)` 加 `arc_segments` 参数：**默认 0
  保持旧弦线行为**——覆铜环判定口径零变化（无关规则零漂移证实）；
  圆心由「弦 + 包含角」反解（规范：angle 逆时针为正），采样点精确落圆上。
- R 矩形圆角参数仍按直角近似：圆角只往矩形内收，直角包络的距离偏小
  = 保守方向。

### 2. 走线板边间距：线段-板框真距离
- 轮廓环每边做包围盒剪枝后取 `_seg_seg_dist` 真距离；跨界/越界段自然
  得 0。无环异常数据退回包围盒口径；source=copper 照旧跳过。
- 金样 2→2 板：八卦键盘 U2_30 **0.300→0.254mm**（真边界比包围盒更近）；
  指尖阅读器 GND 0.263mm 不变。

### 3. 元件间距：spatial hash 全对 + 旋转矩形真距离 + 两道豁免 + 焊盘佐证
旧实现只比 positions 索引相邻 4 项（34 对真实 <1mm 只报 17）、中心距
1.0mm 一刀切、不分正反面。新判据：
- 5mm 网格 3×3 邻域全对检索；体尺寸两路解析（封装名内嵌
  `_L..-W..` / 片式码表 0201~2512），间隙按**旋转矩形精确距离**
  （SAT 判相交 + 4×4 边对真距离）；
- 正反面（side 已知且不同）不配对；Mark/定位孔/测试点/安装孔无体不配对；
  连接器等体尺寸落空的诚实跳过；
- **站立件豁免**：通孔大件（体长 ≥8mm 且有通孔焊盘）架空在板上，
  封装矩形罩住的板面仍可放件——金样判读两例：智能秤 OLED-TH 模块下
  0603（body −9.9mm / 焊盘距 4mm）、星光4N A4988 DIP 载板下 R1206；
- **焊盘佐证门**：封装名内嵌尺寸常含引脚（TDSON-8_L5.9、CAP-TH_L4.2、
  BUZ-SMD_L4.0），体「相交」而焊盘中心距仍 ≥1.5mm 的对是口径噪声，
  跳过——金样判读：真事件焊盘距 0~0.4mm（泰山派金手指 24 对 0402 列
  焊盘贴合 0.0mm、地正星 R10-R12 0.07mm、泰山派3M R476-U63），
  噪声 2.3~4.2mm（可调电源 TDSON×2、AIBox CAP-TH×2、赛博挂坠 BUZZER-D1）；
- 报告形态：聚合一条，列出最紧 5 对及间隙；有被佐证的体相交 WARNING，
  否则 INFO。
- 45° 旋转件的外接框（AABB）口径会把纯侧向 0.61mm 真间隙冤判成
  −0.68 相交（金样可调电源 45° 元件库 38 对、地正星 QFN 对角去耦），
  旋转矩形精确距离后全部消除。

### 4. 差分对等长：链路径长 + 修复分档表死代码
- 网络长度从「全网线段和」改为**链路径长**：chain_segments 串折线，
  分支结点会把贯通路径切断，再在折线端点图上取**树的直径**（两次
  最远点 BFS，按连通分量判环；带环分量保守按总长）。旧口径下 T 型/
  星形网络的支路总和不是任何信号的路径长，支路越多虚高越大。
- **发现并修复 29b9766 的死代码 bug**：`kw in text`（大写关键词 vs
  小写文本）恒 False，`_DIFF_SKEW_BANDS` 整张表从未生效——金样两批
  0 条分档文案（当时「等长 49→49 纯文案对齐」没暴露）。修复后
  USB2.0 档、HDMI/LVDS/MIPI/PCIE/SATA 高速串行 0.5mm 档、ETH
  0.5mm 档真正生效（新增 WARNING 全是真测量：泰山派3M PCIE0_RX
  17.4mm、HDMI_TX_D1 1.75mm、金手指 MIPI_CSI0_D2 0.76mm）。

## 残留与边界

- 元件间距对「封装名内嵌尺寸=体尺寸」的依赖意味着含引脚封装只有
  焊盘佐证门兜着；未来拿到封装库的 courtyard/body 几何应替换。
- 天空星 9 对「0603 焊盘落在 SOIC-8 体内 0.76mm」的几何在数据上自洽
  （走线已接入）但物理不可能，疑似元件锚点数据异常；焊盘距 1.5~2.4mm
  被佐证门跳过。若未来确认为解析器锚点 bug，应修数据源而非放宽规则。
- 差分表外组的小扇出（<1mm）仍按定稿的 2.0mm+10% 相对判据出 INFO。
- 板框层的板内开槽/异形轮廓环作为边界参与距离计算（八卦键盘 17 条
  内部链多为真实开槽）；板框层若有杂散标注线会被误当边界——金样
  未观察到该模式。
