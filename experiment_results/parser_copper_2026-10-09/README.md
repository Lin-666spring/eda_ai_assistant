# 解析器数据补全批（2026-10-09 晚）

台账两项结案 + 两个新发现的解析器真 bug。终版 pytest **1135 passed**，
金样 78 板 **2048 → 1611**（−437），rule_errors 双侧 0。

## 修了什么

| 改动 | 内容 |
|---|---|
| **orphan 焊盘保留** | 陈旧 PAD_NET 记录不再丢弃，保留引脚 + 记录 `metadata["orphan_nets"]`。天线效应 33→12（两脚网络不再被看成单针浮空网） |
| **FILL/POLY 铜形入表** | 带网络的 FILL（R/CIRCLE 子路径）与 POLY 铜形进 `copper_pours`，带外环/内洞几何（mm）。两块电赛扩展板 288/309 片 GND 补丁铜不再「未包含铜皮数据」 |
| **POUR 环几何** | POUR path 解析成外环+内洞坐标 |
| **元件焊盘绝对坐标重建** | `pcb.pads`：封装相对坐标 + 元件位置/旋转（旋转约定经金样验证：GND 焊盘落入 GND 铜 28/28） |
| **铜皮连接规则激活** | 孤岛判定：过孔/焊盘（外环内点，热焊盘 void 不否决）+ 同层走线穿越 + 同网络铜形并查集传递；orphan 网络「无法验证不判」。金样 2 → 29 条 |
| **R 矩形模式语义修正（新发现）** | 规范明确 R X Y W H 的 X/Y 是**左上角**、高度向下延伸；原实现按左下角向上延伸，整块矩形抬一个高度。万兆板整版 GND 铜落板外 170~340mm、台账「泰山派 R 板框 Y 偏一个板高」悬案同根。板边间距 24→45、连接器边沿 31→36 是真板框距离 |
| **多 PCB 文档历史快照（新发现）** | .epru 是追加式日志，**30/78 板含 2~12 个 PCB 文档快照**，原实现全部合并 → 不同版本的元件/走线/覆铜混算（实测 QU1 同时落在新旧两个坐标、U1×12）。改为只解析**最后一个** PCB 文档=最新快照 |

  扩展板不再误报）。

## 判定口径（数据能力边界，写进规则 docstring）

- 孤岛=整片铜区无任何同网络过孔/焊盘/走线接入（含经相邻铜形传递）；
  铜区内部因避让切成的小分片需要填充结果布尔运算，.epru 不含，不判。
- 孤岛残 29 条待判读（LW焊台 JBC±、相框 VBUS 等疑为真孤岛）。
- 手绘 FILL/POLY 与 POUR 同口径判定；orphan 网络不判。

## 坑位

- 金样脚手架必须 `bom_rows_to_items(pcb.bom_items)`（规则要 BOMItem
  对象）+ `pcb_data=pcb` + 传 `pcb.bom_items`（空 BOM 会把 40+ 条
  BOM 规则静默清零，rule_errors 只在整板异常时出现，不报单规则异常）。
- `_rect_corners` 是全局共享函数，板框/POUR/FILL 三处语义同时修正；
  `tests/test_epro2_parser.py` 的 rect_ok 夹具同步改为顶边语义。
