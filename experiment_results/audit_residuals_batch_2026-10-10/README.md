## 改动总览

### A. 结构性恒真 → 真判据（bom_rules.py）
| 规则 | 旧判据（失效模式） | 新判据 |
|---|---|---|
| DC-DC 反馈网络 | 板上任意 ≥2 **行** 电阻即静默（不查网表；一行 R1,R2 只算 1） | 位号计数（`_component_count`）；网表可用 → FB/FEEDBACK/VSENSE 网上 ≥2 个 R 位号引脚；无网表 → 供需（电阻位号 < 2×DC-DC 报） |
| LED 限流电阻 | 板上任意 1 个电阻（100k 上拉也算）全局静默 | 网表逐 LED 查其网络 R/RN 引脚；无网表供需按限流档 47Ω~47kΩ |
| 光耦输入限流 | 「描述含电阻」旧口径（描述空→假阳，有字→静默） | `_is_resistor_row` 统一 + 网表豁免 + 供需 |
| ADC 输入滤波 | 容值搜 pn+desc 子串（真值在 value 列 → 恒假→有 ADC 必报） | `_is_cap_row` + `_parse_capacitance(value)` 落 100pF~1µF 档，pn 回退 |

  无痕迹且有关键网络才报一条 INFO 汇总，不再逐网络「关键词命中=缺测试点」。
