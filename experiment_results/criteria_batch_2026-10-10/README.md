# 判据批：去耦档位真容值 / 串扰最严对排除 GND 族（2026-10-10）

> 「11 条规则真实化」第四批（前三批：解析器 747992a、标准表 29b9766、几何 87ad9b3）。
> 本批两条判据来自覆盖率工程新发现，2026-10-06 抽查台账无对应未结项（勾销步骤为空）。

## 改动

### 1. `_check_power_rail_decoupling`：电容行判定对齐 `_is_cap_row` + 档位真容值
- 旧判据 `part_number` 含「电容/capacitor」——LCSC 料号是 `CL10A…` 式型号、
  描述常为空，金样 78 板 `cap_vals` **恒空 = 整条规则死码**（0 板触发，
  覆盖率口径下也从未在真实 BOM 上生效过）。
- 电容行判定改 `_is_cap_row`（位号前缀 C/CV/CE 优先、描述词回退），
  与片式电容判别口径统一。
- 档位判定从字符串子串改 `_parse_capacitance` 真容值分档：
  小档 47nF~220nF（0.1µF 高频去耦），中档 0.47~22µF（1~10µF 中频滤波）。
  旧子串判据有 **`"1UF" ⊂ "0.1UF"` 恒真 bug**——中频档永不缺档，
  修复后「缺少 1~10μF」才可能真正报出。
- 边界诚实化：无可解析容值 → 跳过不凭空断言；电感值（`UH/MH/NH` 后缀）
  显式排除（normalizer 把 UH 也当 -6 指数会冒充 µF）；`0402` 封装码、
  空值、`50V` 等非容值经 `_parse_capacitance` 落 None 自然跳过。

### 2. `_check_crosstalk_spacing`：最严对标注排除 GND 族
- 金样 71 条串扰违规里 **11 条的「最严重对」是 [信号/GND]**（最大
  金手指板 [GND/HUB_DP7] 200.7mm）——地线贴高速线是隔离/回流手法，
  suggestion 自己也建议「加接地隔离」，把现成的地相邻标成最严 offender
  自相矛盾。
- 新增 `_is_gnd_net`（base.py）：`GND/VSS/EARTH/SHIELD` 四子串判定。
  不走 `_kw_hit`——「gnd」是 3 字母短词要词边界，`AU2GND/AGND/GND_IN`
  全漏；这些缩写是地网络专名、无英文词含这些子串，子串判即可。
  金样 78 板 22 个类地网络名全部被覆盖。
- **只改最严对标注、不改线对计数**：N 对几何事实保留；若该层命中对
  全为 GND 相邻则不再标最严（描述缺省最严重子句）。

## 残留与边界

- `worst = max(平行重叠)` 的「最严」语义仍是重叠长度而非耦合强度
  （3W 串扰能量的真代理是长度×1/d²，属既有设计未动）。
- 串扰层计数含信号-GND 对：几何事实保留是有意的（地相邻仍是「间距 <3W」
  的布局事实），只修了误导性的最严对标注。
- 去耦档位带（47nF~220nF / 0.47~22µF）是工程惯例带而非器件规格，
  未来有网表级「每电源轨」数据时应升级为按轨判定（规则名本意）。
