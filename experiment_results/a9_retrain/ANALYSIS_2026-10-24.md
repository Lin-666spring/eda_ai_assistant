## 一、结论（TL;DR）

1. **重训完成且诚实**：三个模型（TextCNN 意图 / BERT 意图 rbt3 / TextCNN 元件分类）全部在 A-9 模板级无泄漏数据上重训+校准完毕，超参与旧基线对齐（25 / 20+patience6 / 35 epochs，seed 42）。旧产物已备份于 `baseline/`。
2. **val_acc 大跌是挤掉记忆水分，不是退化**：旧 val 集 81%（NLU）/26%（元件）与训练集逐字重复，旧数字测的是记忆。真实句式评估集（84 句分布外）上两个意图模型**双双升至 97.62%（历史最好）**——去泄漏后真实泛化反而更好。
3. **元件分类暴露真实短板**：ic_power 细类 val 召回 20%（1/5），已定位根因（见第五节）并连带**改变了生产 DRC 的检测覆盖**（金样 78 板去耦类发现 130→119）。
4. **论文无影响**：正文/摘要/补充材料/审稿回复均不引用分类器准确率数字，无需改动。竞赛计划书引用的 99.24% 需更新。
5. **4 个测试失败**：3 个校准测试断言基于泄漏时代口径（已过时）；1 个金样快照漂移是重训的直接连带效应（生产语义，需决策处理，见第六节）。

## 四、测试失败分析（全量 1331 过 / 4 失败）

### 4.1 三个校准测试（断言过时，非代码回归）
- `test_calibration_reduces_ece`：断言校准后 ECE ≤ 前。泄漏时代成立；新数据上不成立（上表）。断言本身把"校准必有效"写死，需改口径（允许不降/换更大校准集）。
- `test_intent_model_has_temperature` / `test_component_model_has_temperature`：加载**基础** `.pt` 断言 `temperature != 1.0`。实测备份旧基础 .pt 带 T=0.728/0.782（历史上被校准副本覆盖过）；现行 `calibrate.py` 只写 `*_calibrated.pt`（新 T=1.0303/1.3295 在内），重训后基础 .pt 是纯训练产物（T=1.0 默认）。**测试断言的文件 arrangement 已失效**，应改载 `*_calibrated.pt`——顺带应解决 P1-24"校准产物无人加载"。

### 4.2 金样快照漂移（重训的直接生产影响，需决策）
`test_golden_trigger_counts`：去耦电容检查 130→119、去耦电容距离 20→21、晶振布局 0→1、温度敏感布局 3→2。
该测试自述"计数依赖 torch ML 分类（`_classify_component`）"；`src/rules/bom_rules.py:163,299` 与 `layout_rules.py:214` 生产路径同样走 ML 细类。**重训后 IC 细类召回下降 → 部分电源 IC 不再被识别 → 其去耦类规则不再触发**：这是生产 DRC 检测覆盖的真实收缩（78 板 -11 处发现），不是纯测试问题。处理选项：
- A（推荐，先做）：先做第五节 ic_* 数据增强重训，恢复覆盖后再按测试自带流程重算 `_SNAPSHOT` 并在批次 README 记录；
- B（快速）：接受新基线、立即重算快照——会把覆盖收缩合法化，不建议单独采用。

## 五、ic_power 塌陷根因（已定位，可操作）

新 val 的 5 条 ic_power 全是电源 IC（TPS562201 / TP4056 / LM2596 / XL6009 / RT7272）：

| 模型 | 判对 | 误判去向 |
|---|---|---|
| 旧（泄漏训练） | 4/5（置信 ~0.99） | XL6009→ic_analog |
| 新（无泄漏） | 1/5 | 4 条→ic_analog（置信 0.47~0.90） |

- 误判 4 条的 `desc` 均为空，模型只能凭料号判断；**旧模型的高置信来自泄漏记忆料号**，新模型没见过这些料号就塌向 ic_analog（同封装先验）。desc 在场时（TP4056「锂电池充电管理」）新模型仍判对——生产 BOM 通常带描述，风险部分缓解，但纯料号场景（如协调网表、描述缺失）会漏。
- 修复方向：元件数据生成器为 ic_power 增加料号家族模板（TPS56xx / LM25xx(含 LM2596) / XL60xx / RT72xx / MP15xx / SY72xx / FP67xx 等 DC-DC 与充电 IC 前缀族），让模型学**前缀模式**而非记忆具体料号；ic_mcu（73%）同理可补 STM32xx / GD32xx / CH32xx 家族。
