## 判读结论

### ① 单端 45 条：100% 误报

全部是 SPI1_CLK / USIM_CLK / SDIO_CLK / DCMI_CLK / XTAL_IN / OSC_OUT 一类
时钟名（0.127~0.158mm → Z≈72~78Ω vs 50Ω）。**「时钟按 50Ω」不是任何一块板
的设计要求**——板载时钟做的是长度/边沿管理，不是受控阻抗；真 RF 网络语料里
为 0。旧判据 `single_kw=("rf","clk","clock","osc","xtal")` 里只有 "rf"
站得住。

### ② 差分 252 条（126 对/设计），三种成分

| 成分 | 数量 | 判定 |
|---|---|---|
| 结构性双计（P/N 各报一条） | 全部 | 修复：按对聚合 |
| 表外硬判（RS485×1、WL-SDIO×2 对） | 3 对 | 误报：RS485/CAN/SDIO 无受控阻抗要求，修复前被 `_HIGH_SPEED_IF_KW` 放行 + 默认 100Ω 硬套 |
| 表内接口（USB/HDMI/LVDS/ETH） | 122 对 | **真检出为主**（见下） |

**真检出的证据**：4 层板 LVDS 样本（w=0.152/s=0.305 → 129Ω vs 100）换 JLC
真实叠层（PP 0.21mm/εr≈4.6）复算得 130Ω，同样越界；USB 样本（w=0.158/
s=0.361 → 131Ω vs 90）同理。即这些告警不是 h=0.2 假设的产物——设计者的
线宽/间距组合确实达不到目标阻抗。

**漏判补充**：PCIE 对（REFCLK/RX/TX 共 3 对）此前不在目标表，靠「默认
100Ω」误碰命中——本轮入表明示（MIPI/DSI/CSI、PCIE、SATA 均 100Ω 差分，
语料 47 对按真实标准保留判定）。

### ③ 新检出 1 条单端

ANT 天线馈线（0.158mm → 72Ω vs 50Ω）：2.4G 天线馈线本就要求 50Ω，合理。

## 修复（`_check_impedance_matching`）

④ 单端缩到 RF/天线（`("rf","ant","antenna")` 词边界）；
⑤ 差分按对聚合，一条违规带双网名，w 取对内最小线宽（保守侧）；
⑥ 目标表外不判，表补 MIPI/PCIE/SATA（100Ω）。

## 残留与边界

- h=0.2mm/εr=4.5 兜底只在 4 层板上接近真实（JLC PP 0.21mm）；2/6/10 层板
  偏差大——根因是 .epro2 不含叠层数据。违规文案已带「按厂商叠层参数
  （Polar Si9000）复核」指引；若未来产品拿到真实叠层设置，应替换 h/er。
- 2 层板的 USB/MIPI 对（7 对）定性上同样不达标（换真实 h≈1.2mm 复算越界
  更多），保留判定。
