# 信号完整性与电源完整性 (SI/PI)

> 覆盖 PDN 目标阻抗设计、去耦网络、PAM4 信号完整性、AI 优化 PDN 等前沿话题。

## 目标阻抗法 PDN 设计

### 核心公式

```
Z_target = (VDD × Ripple%) / I_transient
```

| VDD | I_transient | Ripple 5% | Z_target |
|-----|-------------|-----------|----------|
| 0.8V (DDR5 VDD) | 10A | 40mV | 4mΩ |
| 1.1V (DDR5 VDDQ) | 8A | 55mV | 6.9mΩ |
| 1.8V (通用) | 3A | 90mV | 30mΩ |
| 3.3V (外设) | 2A | 165mV | 82.5mΩ |
| 5V (USB/电源) | 2A | 250mV | 125mΩ |

### PDN 阻抗 vs 频率

全频段 PDN 阻抗必须低于 Z_target：

```
DC → 1kHz:   VRM (电压调节模块) 处理
1kHz → 100kHz: 大容量电解电容
100kHz → 10MHz: 中频陶瓷电容 (1-10μF)
10MHz → 100MHz: 小容值 MLCC (0.01-0.1μF)
100MHz → 1GHz:  平面电容 + 封装电容 + 片上电容
>1GHz:         片上电容 (On-die Cap)
```

**反谐振 (Anti-Resonance) 警告**: 并联不同容值电容会在某频率形成并联谐振峰值，阻抗可能超出 Z_target。使用相同 ESL 的电容或添加更多的中间容值来抑制。

## 去耦电容网络设计

### MLCC 自谐振频率 (SRF) 表

| 容值 | 封装 | ESL (nH) | SRF (MHz) | 有效频段 |
|------|------|---------|-----------|---------|
| 0.1μF | 0201 | 0.2 | 35 | 15-80 MHz |
| 0.1μF | 0402 | 0.4 | 25 | 10-60 MHz |
| 1μF | 0402 | 0.4 | 8 | 3-20 MHz |
| 1μF | 0603 | 0.6 | 6.5 | 2-15 MHz |
| 10μF | 0603 | 0.6 | 2.1 | 0.5-5 MHz |
| 10μF | 0805 | 0.8 | 1.8 | 0.3-4 MHz |
| 100μF | 1206 | 1.0 | 0.5 | 0.1-1 MHz |

**关键经验**: 封装比容值更重要！0402 封装 0.1μF 和 1μF 在 >50MHz 时表现几乎相同（因 ESL 相同）。

### DC 偏压特性 (MLCC 杀手)

MLCC 在 DC 偏压下有效容值大幅下降：
- X7R 在额定电压下: 有效容值仅 20-40% 标称值
- X5R 更差: 有效容值仅 10-30% 标称值
- **解决**: 选择 2-3 倍额定电压的电容，或使用更大的封装

### 去耦电容布局金字塔

```
          ┌──────┐ ← IC 裸片 (片上电容)
         ┌┤封装电容├┐
        ┌┤ PCB 小电容 ├┐  0.01-0.1μF 0201/0402 (最近 IC <2mm)
       ┌┤ PCB 中电容  ├┤  1-10μF 0402/0603 (距 IC 2-5mm)
      ┌┤ PCB 大电容   ├┤  10-100μF 0805/1206 (距 IC 5-10mm)
     ┌┤ 板级电解电容  ├┤  >100μF (可在较远位置)
    └──────────────────┘
```

### EIA 三位代码 (MLCC 型号解读)

EIA-198 三位代码：前两位 = 有效数字，第三位 = 乘数 (10^n pF)
- 104 = 10 × 10^4 pF = 100nF = 0.1μF
- 106 = 10 × 10^6 pF = 10μF
- 226 = 22 × 10^6 pF = 22μF
- 476 = 47 × 10^6 pF = 47μF

## PAM4 信号完整性问题

### PAM4 vs NRZ

| 特性 | NRZ (PAM2) | PAM4 |
|------|-----------|------|
| 电平数 | 2 | 4 |
| 每符号 bit | 1 | 2 |
| 眼图开口 | 1× 幅值 | 1/3× 幅值 (每个眼) |
| SNR 要求 | ~20 dB | ~30 dB |
| 对 ISI 敏感度 | 中 | 高 |
| FEC 需求 | 可选 | 必须 |

### 眼图指标

**DDR5 DQ 眼图验收** (6400 MT/s):
- 眼高: ≥240mV（die 端）
- 眼宽: ≥0.7 UI（Unit Interval）
- UI = 1/6400MHz = 156.25ps, 0.7UI = 109.4ps

### 信道非线性效应

- **符号间干扰 (ISI)**: 前一个符号的残余能量影响下一个符号判决
- **串扰 (Crosstalk)**: 相邻通道电磁耦合，PAM4 对串扰的敏感度比 NRZ 高 ~3dB
- **反射 (Reflection)**: 阻抗不连续点产生反射，ISI 加剧
- **抖动 (Jitter)**: 时钟源相位噪声、电源噪声(PSIJ)、通道 ISI 导致的确定性抖动(DJ)

## AI/ML 优化 PDN 设计 (2024-2025 前沿)

### 强化学习自动去耦电容布局
- **方法**: Dueling Double DQN + PPO 搜索最优去耦电容位置和容值
- **效果**: 4 芯片系统 <1 小时内生成完整 PDN 布局（对比人工 ~3 个月）
- **实际应用**: Samsung SSD 中 PCIe 6.0 PSIJ 优化 PDN

### 高斯过程回归替代 EM 仿真
- 预测 PDN 阻抗关键特征（谐振频率），RMSE ~3%
- 大幅减少昂贵的全波 3D 电磁仿真次数
- 数据高效的替代方案，可在设计早期快速评估 PDN 性能

### 448 Gbps+ 互连挑战 (Ciena/OIF 2025)
- 共封装光学 (CPO): Nvidia Spectrum-X CPO 与传统可插拔模块比 SI 改善 63×
- 裸片-封装边界、过孔、柔性电缆和连接器的过渡不连续性
- 裸片上 PDN 谐振在 10GHz+ 范围

## 串扰控制

### 3W 规则详解

| 间距 | 串扰抑制 | 适用场景 |
|------|---------|---------|
| 1W | ~-20dB | 不允许高速信号 |
| 2W | ~-28dB | 低速数字 |
| 3W | ~-35dB | 通用数字 (标准间距) |
| 5W | ~-45dB | 高速/敏感信号 |
| 10W | ~-60dB | RF/超敏感模拟 |

- W = 线宽
- 3W 规则: 边到边间距 ≥ 3 × 线宽
- 40dB+ 隔离（RF 要求）需要 ≥7W 或使用地线隔离

### 层间串扰

- 相邻信号层之间必须有完整的平面层隔离
- 微带线对外层间距 ≥2H (H=介质厚度)
- 高速信号不要平行走长距离

### 差分对串扰抑制
- 差分对对相邻差分对间距 ≥5S (S=差分对内间距)
- 相同方向走线的差分对必须错开间距

### Hammerstad 铜箔粗糙度模型

```
α_rough = α_smooth × [1 + (2/π) × arctan(1.4 × (Rq/δ)^2)]
```
其中 Rq=铜箔 RMS 粗糙度, δ=趋肤深度

| 铜箔类型 | Rq (μm) | 28GHz 插入损耗 (dB/inch) |
|---------|---------|--------------------------|
| 标准 RTF | 3-5 | 3.5-4.5 |
| VLP (超低轮廓) | 1.5-2.5 | 2.0-3.0 |
| HVLP (高精度超低轮廓) | 0.5-1.0 | 1.0-1.5 |

## 常见陷阱

### 陷阱一: 目标阻抗计算忽略瞬态电流
**问题**: Z_target = VDD × Ripple / I_transient 中的 I_transient 用的是平均电流而非瞬态峰值电流。实际瞬态电流可达平均值的 3-5 倍。**正确**: 使用瞬态电流或留 3-5× 裕量。

### 陷阱二: MLCC DC 偏压特性被忽略
**问题**: 6.3V X7R 1μF 在 5V 偏压下有效容值仅 ~0.3μF，去耦效果大打折扣。**正确**: 选 2-3 倍额定电压，或用电容仿真工具检查 DC 偏压曲线。

### 陷阱三: 反谐振未处理
**问题**: 并联 0.1μF 和 10μF，在两者 SRF 之间的某频率形成高阻抗谐振峰，PDN 阻抗超过 Z_target。**正确**: 增加中间容值（如 1μF）填补频段缺口，或选择相同 ESL 的电容。

### 陷阱四: 只用一个容值去耦
**问题**: 满板都是 0.1μF，低频（<1MHz）完全靠 VRM，VRM 到负载的 PCB 走线电感导致瞬态电压跌落。**正确**: 遵循"大中小"三级去耦金字塔。

### 陷阱五: 过孔反焊盘过大
**问题**: 为了制造方便把反焊盘开得很大，破坏了参考平面的完整性，增加回流环路面积。**正确**: 反焊盘比过孔直径大 20-30% 即可。
