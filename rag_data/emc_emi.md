# EMC/EMI 电磁兼容设计

> 覆盖 PCB 级 EMI 抑制、EMC 合规设计、屏蔽/滤波/ESD 防护策略。

## 核心原理

- **EMC = 低 EMI（发射）+ 高 EMS（抗扰度）**
- 辐射的产生：电荷加速 → 天线效应 → 电磁波辐射
- **设计目标：实现零净加速电荷** —— 信号电流和返回电流路径完全对称紧耦合
- **以场的思维设计，而非仅电压/电流** —— 能量和信息在电磁场中传输，不在铜导体中

## 返回路径与环路控制

### 最小环路面积原理 (规则 #1)

信号电流总是以环路形式返回其源。在高频（>1MHz），返回电流遵循**最小电感路径**——直接在信号走线正下方的参考平面上流动。

```
LOOP AREA = 信号走线长度 × (信号层到参考层距离)
```

| 信号类型 | 上升时间 | 返回路径机制 | 关键关注点 |
|---------|---------|------------|----------|
| DC/低频 (<100kHz) | >1μs | 最小电阻路径 (直线) | IR drop |
| 中频 (100kHz-10MHz) | 10ns-1μs | 混合 (电阻+电感) | 环路面积增大 |
| 高频 (>10MHz) | <10ns | **最小电感路径 (正下方)** | EMI 辐射 |

**经验法则**: 更大环路面积 = 更强天线效应 = 更多辐射

### 跨分割回流

当信号走线跨越参考平面上的开槽/分割时，返回电流被迫绕行——环路面积剧增，成为差模辐射源。

**绝不允许高速信号跨越参考平面分割！**

**解决方案**:
- 使用连续完整的地平面
- 如有不同电源域，使用 stitching capacitor（0.01μF + 1μF）桥接
- 绝不依赖直流接地——高频返回路径必须通过耦合（位移电流）

## 3W / 20H 规则

### 3W 间距规则

| 间距 (边到边) | 串扰抑制 | 备注 |
|-------------|---------|------|
| 1W | ~20dB | 仅低速信号 |
| 2W | ~28dB | 一般数字信号 |
| 3W | ~35dB | **标准设计间距** |
| 5W | ~45dB | 高速/时钟信号推荐 |
| 10W | ~60dB | RF 敏感信号 |

### 20H 电源层收缩规则

电源平面边缘从地平面边缘向内缩进 **20 × H**（H = 电源-地间距）：

```
缩进量 = 20 × H
例: H = 0.2mm → 缩进 4mm
```

效果: 边缘辐射降低 5-10 dB。但对多层板（≥6层）效果有限——内部层已有良好屏蔽。

## 屏蔽设计

### 屏蔽腔谐振

封闭金属屏蔽腔在特定频率会产生谐振（类比微波炉）:

```
f_res = C / 2 × sqrt((m/L)² + (n/W)²)
```
C=光速, L/W=腔体尺寸, m/n=模式数

**避免办法**:
- 使用微波吸收材料（吸波片）贴在腔内
- 调整腔体尺寸避开工作频率
- 多个小腔替代一个大腔

### 过孔围栏 (Via Fence / Stitching)

RF 走线两侧的地过孔：
- **间距**: ≤ λ/10（如 2.4GHz → λ≈62mm → 间距 ≤6.2mm）
- **推荐间距**: λ/20（更严格的隔离）
- 双排过孔提供更强的隔离度

## 滤波与 ESD 防护

### 共模扼流圈 (Common Mode Choke)

| 参数 | 信号用 | 电源用 |
|------|--------|--------|
| 共模阻抗 | 90Ω @ 100MHz | 500-2000Ω @ 100MHz |
| 差模阻抗 | <5Ω | <10Ω |
| 额定电流 | 0.1-1A | 1-10A |

### X/Y 电容

| 类型 | 安规 | 典型值 | 用途 |
|------|------|--------|------|
| X1 | 脉冲 4kV | 0.1-1μF | 跨 L-N 滤波 |
| X2 | 脉冲 2.5kV | 0.1-1μF | 跨 L-N (通用) |
| Y1 | 双绝缘 8kV | 1-4.7nF | 跨一二次侧 |
| Y2 | 基本绝缘 5kV | 1-4.7nF | 跨一二次侧 (通用) |

### TVS 管选型

| 接口 | VRWM (V) | Vclamp @ Ipp | 结电容 (pF) | 推荐型号系列 |
|------|---------|-------------|------------|------------|
| USB 2.0 (D+/D-) | 5 | <10V | <3 | RCLAMP0502B |
| USB 3.0 (SS) | 3.3 | <8V | <0.5 | TPD4E05U06 |
| HDMI | 5 | <10V | <0.5 | CM2020 |
| RS-485 | 12 | <20V | <10 | SM712 |
| GPIO | 3.3-5 | <15V | <5 | PESD5V0 |

### 铁氧体磁珠

- 用于电源线上抑制高频噪声（等效于频率依赖的电阻）
- 阻抗选择: 电源线 30-120Ω @ 100MHz，信号线 10-60Ω
- 注意 DC 偏流降额——DC 电流越大，有效阻抗越低
- 不要串联多个磁珠——可能引起谐振

## 原理图级 EMI 预防

1. **尽早定义电源域** —— 高速数字、RF、模拟、电源域分开
2. **明确标注地类型** —— AGND、DGND、PGND 并定义层次
3. **每个连接器加滤波** —— PI 滤波器或铁氧体磁珠
4. **预留滤波元件** —— 若不需要可不装，但保留 PCB footprint
5. **未用 GPIO 不悬空** —— 接地或 VCC（通过电阻），防止天线效应
6. **所有外部 I/O 加 ESD 保护**

## 常见陷阱

### 陷阱一: 错误认为"数字信号不需要EMC"
**问题**: 认为只有 RF/模拟电路需要 EMC 设计。**事实**: 现代数字信号的边沿速率（<100ps）含有高达 3-5GHz 的谐波，是最强的 EMI 源。

### 陷阱二: 分割地平面
**问题**: 将模拟地和数字地物理分割以"隔离噪声"。**事实**: 分割地平面创造偶极子天线，回流电流被迫绕行大环路，反而增加 EMI。**正确**: 使用统一连续地平面 + 物理分区。

### 陷阱三: 屏蔽腔接地不良
**问题**: 屏蔽罩只在一端或少数几处接地，形成缝隙天线。**正确**: 屏蔽罩多点低阻抗接地，接地间距 ≤λ/20。

### 陷阱四: 滤波电容谐振点选择错误
**问题**: 用 0.1μF 去耦 100MHz 时钟的 EMI，但 0.1μF 在 >80MHz 已成感性（阻抗上升）。**正确**: 高频滤波用 10-100pF NP0/C0G 电容。

### 陷阱五: 忽略连接器 EMI
**问题**: PCB 本体设计良好，但连接器处无滤波/ESD/屏蔽，成为 EMI 泄漏点。**正确**: 连接器处加共模扼流圈、TVS、RC 滤波，金属外壳连接器可靠接地。
