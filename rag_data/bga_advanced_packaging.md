# BGA 扇出与先进封装技术

> 覆盖不同间距 BGA 的扇出策略、微孔/HDI/VIPPO 设计、先进封装趋势。

## BGA 间距与过孔策略总表

| BGA 间距 | 焊盘直径 | 可用通道宽度 | 扇出策略 | 过孔类型 | 板层需求 |
|---------|---------|------------|---------|---------|---------|
| 1.27mm | 0.6mm | 0.67mm | 狗骨/通孔 | 机械通孔 0.3mm | ≥4层 |
| 1.0mm | 0.5mm | 0.5mm | 狗骨/通孔 | 机械通孔 0.25mm | ≥4层 |
| 0.8mm | 0.4mm | 0.4mm | 狗骨 (外层) | 机械通孔 0.2mm | ≥6层 |
| 0.65mm | 0.35mm | 0.3mm | 盘中孔 (外排) | 激光微孔 0.1mm | ≥8层 |
| 0.5mm | 0.3mm | 0.2mm | **盘中孔必须** | 激光微孔 0.1mm | ≥10层 + HDI |
| 0.4mm | 0.25mm | 0.15mm | **盘中孔必须** | 激光微孔 0.075mm | 任意层 HDI |
| 0.35mm | 0.2mm | 0.15mm | **盘中孔 + 任意层HDI** | 激光微孔 0.075mm | 任意层 HDI |

### 狗骨 (Dog-Bone) 扇出示意图

```
BGA 焊盘 ──── ○ (过孔)
  (SMD)       (通孔)
   ○──────────○  → 引线连接到内层
```

### 盘中孔 (Via-in-Pad) 扇出示意图

```
BGA 焊盘
  ○  ← 过孔从焊盘中心直下
  │
  ▼ → 内层走线
```

## 不同间距的扇出详解

### 1.27mm 间距 (宽间距 BGA)

**最宽松，标准多层板即可**:
- 外层可用通孔 (0.3mm钻孔 / 0.6mm焊盘)
- 走线宽度 0.15-0.2mm (6-8mil)
- 两排焊盘间可布 1-2 条走线

**扇出模式**: 外侧两排直接扇出，内侧焊盘通过通孔连接到内层

### 1.0mm 间距 (标准 BGA)

**常见于 MCU/FPGA**:
- 使用 0.25-0.3mm 机械通孔
- 狗骨引线长度 <1mm
- 外侧 2-3 排可直接扇出，内侧需内层走线

### 0.8mm 间距 (密集 BGA)

**挑战增大，需 6 层板起**:
- 必须使用 0.2mm 机械钻孔
- 外侧 2 排可狗骨扇出
- 内侧必须使用通孔下到内层
- 走线宽度 0.1-0.15mm (4-6mil)

### 0.65mm 间距 (高密度 BGA)

**需要 HDI 技术**:
- 外排使用盘中孔 (激光钻孔 0.1mm)
- 内排可能需要 1+N+1 HDI 结构
- 推荐 8 层板以上

### 0.5mm 间距 (超密 BGA)

**必须使用盘中孔 + 微孔**:
- 激光钻孔 0.1mm，盘中孔填充 + 铜盖
- 2+N+2 或任意层 HDI 结构
- 走线宽度 0.075-0.1mm (3-4mil)

**工艺注意**: 盘中孔必须用非导电环氧树脂填充 + 铜盖，防止回流时焊料芯吸（solder wicking）。

### 0.4mm 间距 (极限 BGA)

**任意层 HDI 必须**:
- 激光钻孔 0.075-0.1mm
- 堆叠微孔（非交错）以节省空间
- 每个微孔最多堆叠 2 个
- 填充铜或树脂 + 铜盖

## 微孔 (Microvia) 设计

### 微孔参数

| 参数 | 推荐值 | 极限值 | 备注 |
|------|--------|--------|------|
| 激光钻孔直径 | 0.1mm | 0.075mm | 与铜厚相关 |
| 深宽比 (Aspect Ratio) | ≤0.8:1 | ≤1:1 | 激光钻孔的深度/直径 |
| 捕捉焊盘 (Capture Pad) | ≥钻孔直径 × 1.5 | ≥钻孔直径 × 1.2 | 确保对准余量 |
| 微孔堆叠 | ≤2 层 | ≤3 层 | 堆叠过多 CTE 失配风险 |
| 微孔交错 | 任意 | — | 交错结构比堆叠更可靠 |
| 底部焊盘 | 大于微孔直径 + 0.1mm | — | |

### 堆叠 vs 交错微孔

```
堆叠 (Stacked):          交错 (Staggered):
L1 ○ ← 微孔               L1 ○ ← 微孔1
    │                         \
L2 ○ ← 微孔                   L2 ○ ← 微孔2
    │                           \
L3 ○                            L3 ○
堆叠: 更小面积              交错: 更可靠
可靠性: 较差 (CTE失配)      可靠性: 更好
```

**推荐**: 优先使用交错结构，只有实在放不下时才用堆叠。

### 微孔填充工艺

| 填充方式 | 优点 | 缺点 | 适用 |
|---------|------|------|------|
| 电镀填铜 | 导电好,散热好 | 成本高, 耗时长 | VIPPO |
| 非导电环氧树脂 | 成本低, 工艺简单 | 不导电, 散热差 | 普通盘中孔 |
| 导电银浆 | 导电, 成本中 | 可靠性中等 | 少量应用 |
| 铜塞 (Copper Plug) | 散热最好 | 工艺复杂 | 高功率器件 |

## VIPPO (Via-in-Pad Plated Over) 技术

### 什么是 VIPPO

过孔放置在 SMD 焊盘正下方，填充后表面电镀铜覆盖，使焊盘平整如常。贴片时不易产生空洞。

### 核心要求

- 过孔必须**完全填充**（环氧树脂或电镀铜）
- 表面铜盖: ≥15μm，平整度 ≤15μm
- 填充无空隙、无裂纹
- 金相切片验证填充质量

### 应用场景

- 0.5mm 及以下间距的 BGA 扇出
- 高速信号过孔（减少 stub）
- 空间极度受限的设计

### 成本权衡

VIPPO 的增量成本通常**小于为避开过孔而增加 2+ 层 PCB 的成本**。

## HDI 结构

### 常见 HDI 堆积结构

| 结构 | 微孔层数 | 总层数 | 最小 BGA 间距 | 相对成本 |
|------|---------|--------|-------------|---------|
| 1+N+1 | 2层微孔 | N+2 | 0.65mm | 1.2× |
| 2+N+2 | 4层微孔 | N+4 | 0.5mm | 1.5× |
| 3+N+3 | 6层微孔 | N+6 | 0.5mm | 2.0× |
| 任意层 (Any-Layer) | 全部微孔 | 任意 | 0.4mm | 2.5-3× |

### 部分 HDI 策略

对于仅局部有细间距 BGA 的设计:
- 只在 BGA 区域使用微孔层
- 其余区域使用标准通孔
- 例如: 10 层板，顶层 2 层微孔覆盖 BGA，内部 8 层标准通孔
- 避免全板 HDI 成本

## 林荫道布线 (Boulevard Routing)

### 原理

利用盲孔阵列在 BGA 下方形成规则通道网格，类似城市街道的"林荫道"系统：
- 十字形: 水平和垂直通道
- L 形: 仅在两个相邻方向
- 对角线: 45° 通道

### 效率对比

对于高引脚数 BGA (如 1153 脚 1mm 间距):
- 通孔扇出: 需要 8-10 个信号层
- 盲孔林荫道: 仅需 2-3 个信号层
- **减少信号层达 4 倍**

## 先进封装趋势

### Chiplet (芯粒) 设计

- 多个小芯片通过 interposer 互连
- 2.5D 封装 (硅中介层) / 3D 封装 (垂直堆叠)
- PCB 需要适应超高密度互连 (微凸点间距 40-55μm)

### Fan-Out 封装

- 芯片焊盘"扇出"到更大面积的再分布层 (RDL)
- 不需要封装基板（比 BGA 更薄更便宜）
- PCB 设计中 Fan-Out 封装通常有更少的 I/O 但更高的密度

## 常见陷阱

### 陷阱一: 0.4mm 间距 BGA 用常规 PCB 工艺
**问题**: 设计 0.4mm BGA 但指定用普通通孔狗骨扇出 → 物理上不可实现。**正确**: 0.5mm 以下必须用 HDI + 盘中孔，与 PCB 工厂确认能力后再设计。

### 陷阱二: 盘中孔未饱满填充
**问题**: 盘中孔填充不饱满或有空洞 → 回流焊接时焊料芯吸入孔内 → BGA 焊点虚焊。**正确**: 指定非导电环氧树脂填充 + 表面铜盖，IPC-6012 Class 3 验收标准。

### 陷阱三: 微孔堆叠超过 2 层
**问题**: 堆叠 3 层微孔以节省面积 → CTE 失配导致热循环中微孔底部开裂。**正确**: 堆叠最多 2 层，3 层以上必须用交错结构并做可靠性验证。

### 陷阱四: 反焊盘过大导致平面断裂
**问题**: BGA 区域大量过孔反焊盘连成片，地/电平面被严重切割。**正确**: 反焊盘尺寸控制在过孔直径的 1.3-1.5 倍，绝不连片。

### 陷阱五: 忽略板厂 HDI 能力
**问题**: 设计了任意层 HDI，但目标板厂最多只支持 2+N+2。**正确**: 设计前确认板厂的 HDI 能力（最大层数、最小激光孔径、微孔填充工艺）。
