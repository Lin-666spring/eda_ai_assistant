# 混合信号与 RF 设计指南

> 覆盖模拟/数字/RF 分区隔离、统一接地、ADC/DAC 布局、射频阻抗控制。

## 核心原则: 统一地平面

### 2024-2025 最大共识

模拟和数字地 **不要物理分割**。使用一个连续完整的地平面 + 组件物理分区。

**为什么？**
1. 分割地平面创造偶极子/环路天线 → 回流电流被迫绕行 → EMI 失败
2. 只需一根走线跨越分割，整个隔离设计就前功尽弃
3. 现代芯片的 AGND/DGND 引脚内部已经连接——分割地面会产生地弹

**怎么做？**
- 使用**一个实心地平面**覆盖整个 PCB
- 通过**组件放置和布线规范**（而非铜切割）使数字回流限于数字区域
- 模拟/数字区域物理分离，留足够间距

## 物理分区

### 功能分区原则

```
┌──────────────────────────────────┐
│  RF前端          数字基带          │
│  (LNA/PA)      (MCU/DSP)         │
│                 ┌──────┐         │
│  模拟信号链     │ADC/DAC│         │
│  (运放/滤波)    │ 边界  │         │
│                 └──────┘         │
│    电源管理区域                   │
└──────────────────────────────────┘
```

- 按照信号流拓扑排列: RF 前端 → IF 级 → ADC/DAC 边界 → 数字基带
- RF 组件/走线与其他电路保持 ≥10mm 间距
- 高功率 RF (PA) 与低噪声 RF (LNA) 分开——最好放在板的相对边缘

### 推荐 4 层混叠设计

```
L1 (顶层): RF 信号 + 低速数字 (在完整地平面上布线)
L2: 连续地平面 (关键返回路径, 不分切)
L3: 电源平面 (模拟/数字区域可用宽走线分隔)
L4 (底层): 低速数字/信号
```

### ADC/DAC 边界设计

- ADC/DAC 跨越模拟和数字域的边界
- **将其视为带数字接口的模拟器件**（而非带模拟输入的数字器件）
- AGND 和 DGND 引脚都连接到 IC 下方的**模拟地平面**（不可分地）
- 数字接口走线从 ADC 引出后立即进入数字区域

## 接地技术

### 过孔围栏 (Via Fence / Stitching Wall)

RF 走线周围的地过孔：
```
GND ○   ○   ○   ○   ○  ← 过孔围栏
     \  RF trace  /
GND ○   ○   ○   ○   ○  ← 过孔围栏
```

- **间距**: ≤ λ/10（2.4GHz: λ≈62mm → ≤6.2mm）
- **高精度**: ≤ λ/20
- 双排过孔为高功率设计提供更强隔离
- 关键信号需要两侧过孔围栏

### 星形接地

- 所有地回路最终在**一个点**汇合（通常为电源入口处）
- 避免多点接地形成地环路
- 低频率（<1MHz）特别有效——高频靠平面电容耦合

### 域交叉处理

当信号必须跨越模拟/数字边界时：
- 使用铁氧体磁珠（低频隔离）
- 使用屏蔽传输线（高频隔离）
- 使用数字隔离器（I2C/SPI 隔离芯片）
- **绝不**让高速数字走线穿过模拟区域

## 电源隔离

### 独立稳压

- RF 和数字电路使用**独立的 LDO**
- 从不将电源从一个 RF 块串到另一个——使用**星形拓扑**分配
- 每个 LDO 输入输出加去耦电容

### 电源滤波链

```
DC_IN → 铁氧体磁珠 → 大电容 (10μF) → 中电容 (1μF) → 小电容 (0.1μF) → IC VCC
```

铁氧体磁珠选择:
- RF 模拟电源: Z ≥ 300Ω @ 100MHz, R_DC < 0.1Ω
- 数字电源: Z ≥ 120Ω @ 100MHz, R_DC < 0.05Ω

## 射频阻抗控制

### 特征阻抗公式

**微带线 50Ω**:
```
Z0 = 87 / sqrt(εr + 1.41) × ln(5.98 × H / (0.8 × W + T))
```

**共面波导 (CPW) 带地**:
- 信号走线两侧有地铜皮（间隙 G）
- Z0 由 W, G, H, εr 决定
- 比微带线更好的隔离度（两侧地过孔屏蔽）

### 50Ω 标准

| 频率 | 应用 | 阻抗 | 介质 | W/H 比 |
|------|------|------|------|--------|
| 433 MHz | ISM 遥控 | 50Ω | FR-4 | 1.8 |
| 915 MHz | ISM | 50Ω | FR-4 | 1.8 |
| 2.4 GHz | WiFi/BLE | 50Ω | FR-4/RO4350 | 1.6-2.0 |
| 5.8 GHz | WiFi 5G | 50Ω | RO4350 | 1.6 |
| 24 GHz | 毫米波雷达 | 50Ω | RO4003 | 1.5 |

### 阻抗不连续性处理

- 拐角: 使用 45° 切角或圆弧，禁用 90°（产生容性突变）
- 过孔: 反焊盘优化直径，若无必要 RF 走线避免过孔
- 线宽变化: 渐变过渡（taper），不突变
- 连接器焊盘: 调整焊盘尺寸和形状匹配 50Ω（需仿真确认）

## RF 布局布线最佳实践

### 顶层 10 条规则 (2024-2025)

1. **使用一个连续地平面** —— 不分切
2. **物理分区** —— RF、模拟、数字区域有明确边界
3. **RF 走线短且直** —— 50Ω 受控阻抗，在无断裂地平面上方
4. **过孔围栏** —— RF 走线周围 λ/10 间距地过孔
5. **电源分离** —— 每个域星形分配 + 独立 LDO
6. **多值去耦** —— 最小电容最靠近 IC 引脚
7. **按域布线** —— 数字信号在所有层保持在数字区域内
8. **控制数字边沿速率** —— 串联电阻/RC 滤波降低边沿速率
9. **混合叠层** —— RF 级层压板 + FR-4 混压
10. **尽早与制造商协作** —— 确认叠层、阻抗、材料

### RF 走线细节

- 避免 RF 路径中的过孔——优先表面层布线
- 如必须使用过孔: 最多一个, 最小 stub, 3 个地过孔环绕
- 使用共面波导 (CPW) 结构提高隔离度
- 晶振电路: 负载电容紧靠晶振引脚，晶振下方不走其他信号线

### π 型衰减器 / 匹配网络

```
IN ─┬─ R1 ─┬─ OUT
    R2     R3
    GND    GND
```

- 用于 RF 输入/输出阻抗匹配
- 通常放于 RF 连接器和 RF IC 之间
- 元件值通过 Smith 圆图或仿真确定

## 天线设计要点

### PCB 天线类型

| 类型 | 增益 | 带宽 | 面积 | 适用 |
|------|------|------|------|------|
| 倒 F 天线 (PIFA) | 0-3 dBi | 窄 | 中 | 2.4GHz WiFi/BT |
| 蛇形天线 (Meander) | -2-2 dBi | 窄 | 小 | 915MHz/433MHz |
| 陶瓷贴片天线 | 1-4 dBi | 中 | 小 | GPS/北斗 |
| 偶极子 (外置) | 2-5 dBi | 宽 | 大(外部) | 通用 |

### 天线布局规则

- 天线区域下方所有层清铜（地平面掏空）
- 天线周围 ≥5mm 无铜、无金属件
- 天线匹配网络紧靠天线馈点
- 50Ω 馈线尽可能短

## 常见陷阱

### 陷阱一: 模拟地和数字地分离后被接回错误位置
**问题**: 设计时将 AGND 和 DGND 物理分割，然后在一个点用磁珠或 0Ω 电阻连接——但这个"单点"位置不对，地环路依然存在。**正确**: 不去分割，使用统一连续地平面。

### 陷阱二: ADC 采样时钟噪声
**问题**: ADC 使用 MCU 内部 RC 振荡器或 PLL 生成的时钟，相位噪声大，SNR 劣化 6-10dB。**正确**: 高精度 ADC 使用外部低抖动晶振（相位抖动 <1ps RMS）。

### 陷阱三: RF 阻抗不连续
**问题**: RF 走线经过连接器/过孔/焊盘时阻抗变化导致反射。**正确**: 每个过渡点设计阻抗匹配结构，必要时用 Smith 圆图验证。

### 陷阱四: 数字走线穿越模拟区域
**问题**: "只一条低速 I2C 走线穿过应该没关系" — 实际数字边沿的谐波高达数百 MHz，可以直接耦合到模拟输入端。**正确**: 严格按域布线，绝不让任何数字信号穿越模拟区域。

### 陷阱五: 忽略 RF 屏蔽与天线耦合
**问题**: 屏蔽腔过小导致谐振频率在天线工作频段内，吸收天线辐射功率。**正确**: 屏蔽腔谐振频率远离工作频率至少 ±20%。
