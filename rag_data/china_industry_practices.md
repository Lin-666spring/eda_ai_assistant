# 中国 PCB 行业实践与本土经验

> 覆盖立创EDA DRC 配置、嘉立创下单技巧、华为设计规范精要、国产替代策略。

## 立创EDA (LCEDA) 设计规则配置

### DRC 规则设置入口

1. **安全间距**: 设计 → 设计规则 → 间距 → 安全间距
2. **导线宽度**: 设计 → 设计规则 → 物理 → 导线
3. **过孔尺寸**: 设计 → 设计规则 → 物理 → 过孔尺寸
4. **差分对**: 设计 → 差分对管理器 → 设置线宽/间距/长度误差
5. **网络类**: 设计 → 网络类管理器 → 电源/地网络分组
6. **DRC 检查**: 设计 → 检查 DRC → 实时检查

### 推荐 DRC 规则模板 (立创EDA专业版)

| 规则项 | 推荐值 | 说明 |
|--------|--------|------|
| 安全间距 (标准) | 6mil (0.152mm) | 通用数字信号 |
| 安全间距 (高压 >48V) | 20mil (0.5mm) | 爬电距离 |
| 最小线宽 (信号) | 6mil (0.152mm) | 留余量，不踩 3mil |
| 最小线宽 (电源) | 12mil/A (1oz铜) | 1A至少12mil |
| 最小线宽 (电源 2A+) | 24mil+ | 大电流 |
| 最小过孔孔径 | 0.3mm | 机械钻孔 |
| 最小过孔外径 | 0.6mm | 孔径 × 2 |
| 阻焊开窗扩展 | 0.1mm (3.9mil) | |
| 铜到板边 | 0.3mm | |
| 字符线宽 | 6mil | |
| 字符高度 | 32mil (0.8mm) | |

### 网络类设置

在立创EDA中为不同网络设置不同规则：
- **PWR 类** (VCC/5V/3.3V/VDD等): 线宽 ≥12mil，过孔外径 ≥0.8mm
- **GND 类**: 优先使用覆铜，过孔外径 ≥0.6mm
- **DIFF 类** (USB/HDMI/ETH等): 设置差分对线宽/间距/等长公差
- **RF 类**: 设置 50Ω 特征阻抗管控

### 立创EDA专业版 vs 标准版

| 功能 | 标准版 | 专业版 |
|------|--------|--------|
| 最多层数 | 4层 | 无限 |
| 差分对设置 | 基础 | 完善 |
| 阻抗管控 | 无 | 支持 |
| 盲埋孔 | 2层 | 任意 |
| 多人协作 | 基础 | 支持 |
| 文件格式 | JSON (.json) | epro (.zip) |
| 导出 Gerber | 支持 | 支持 |
| 从 AD/Altium 导入 | 部分 | 更好 |

### 从 Altium Designer 迁移到立创EDA

- AD 原理图可导出为 ASCII 格式后导入立创EDA
- AD PCB 可通过 ODB++ 或 P-CAD ASCII 导入
- 封装库需要重新映射——库名称不通用
- DRC 规则需要手动重新设置

## 嘉立创 (JLCPCB) 下单技巧

### 打样 vs 批量

| 参数 | 打样 | 小批量 | 大批量 |
|------|------|--------|--------|
| 数量 | 5-10片 | 50-500片 | 1000+片 |
| 交期 | 24-48h (常规) | 3-5天 | 5-10天 |
| 价格策略 | 低价打样 | 面积计价 | 面积+套餐 |
| 颜色可选 | 绿/蓝/红/黑/白 | 全色 | 全色 |
| 特殊工艺 | 可选 | 可选 | 可选 |

### 下单检查单

1. ☐ Gerber 文件是否完整（所有层 + 钻孔 + 钻孔表）
2. ☐ 板外形是否闭合（Board Outline 层不能断开）
3. ☐ 最小线宽/线距 ≥4mil
4. ☐ 最小钻孔 ≥0.3mm
5. ☐ 铜到板边 ≥0.3mm
6. ☐ 阻焊开窗是否正常（不覆盖焊盘）
7. ☐ 丝印是否清晰可辨（字符宽度≥6mil, 高度≥32mil）
8. ☐ 过孔是否都盖油或开窗（按需选择）
9. ☐ 阻抗管控是否在下单时勾选
10. ☐ BOM 坐标文件是否一同上传

### 生产报告解读

下单后系统生成的 DFM 报告需检查:
- **线宽线距不足**: 红色标记需修改，黄色尽量修改
- **孔环不足**: 可能导致钻孔破环
- **阻焊桥过窄**: 可能被绿油填充
- **槽孔/异形孔**: 确认是否在生产能力内

## 华为 PCB 设计指南要点

### 华为硬件 10 条硬规 (业界流传版本)

1. 电源走线: 200mA 以上电流，走线宽度 ≥1mm (1oz铜)
2. 每个 IC 至少 1 个去耦电容 (0.1μF)，距 IC 引脚 ≤5mm
3. 晶振负载电容紧靠晶振引脚放置
4. BOOT0/配置引脚必须明确上下拉，不得悬空
5. 外部连接器所有引脚必须加 ESD 保护
6. 大功率器件背面铺铜 + 散热过孔
7. 高速差分信号 (USB/ETH/HDMI) 对内等长 ≤5mil
8. 模拟地和数字地不分割，使用统一地平面 + 物理分区
9. 电源入口加 TVS 管 + 自恢复保险
10. 所有未使用 GPIO 通过 10kΩ 电阻上拉或下拉（不得悬空）

### 华为高速设计规范

- DDR 信号线长度控制在芯片规格的 0.75× 以内（留时序裕量）
- PCIe AC 耦合电容优先放 TX 端
- 差分对不允许跨分割，参考平面必须连续
- 背钻残桩控制: stub ≤0.15mm (5Gbps+)

### 立创商城 LCSC 编号技巧

- LCSC 编号格式: Cxxxxx (如 C12345)
- 在立创EDA中直接搜索 LCSC 编号可以自动加载元件参数和封装
- BOM 表中务必填入正确的 LCSC 编号（而非其他商城编号）
- 如果某元件在 LCSC 没有库存，可在立创商城搜索替代型号
- LCSC 的"基础库"元件比"扩展库"交货更稳定

### 国产化设计建议

1. **优先选择国产基础库元件** —— 交货周期短，价格稳定
2. **关键 IC 保留备用封装** —— 引脚兼容的第二供应商
3. **关注车规/工规认证** —— 部分国产芯片已有 AEC-Q100 认证
4. **留意 Errata** —— 国产芯片的数据手册可能有遗漏，多查阅用户反馈

## 中国标准与认证

### CCC 强制认证 (对 PCB 相关产品)

- 信息技术设备 (GB 4943.1-2022): 安全要求
- 音视频设备 (GB 8898): 安全要求
- 锂电池 (GB 31241): 强制 CCC

### 中国 RoHS (GB/T 26572-2011)

- 限制: 铅、汞、镉、六价铬、PBB、PBDE
- 与 EU RoHS 基本一致，但有中国特有的标识和声明要求
- 标识: 绿色 e 标志或橙色数字标志（含年限）

### GB/T 与 IPC 差异

| 项目 | GB/T | IPC | 差异 |
|------|------|-----|------|
| 印制板设计 | GB/T 4588.3 | IPC-2221 | 电压等级分类方式不同 |
| 印制板鉴定 | GB/T 4677 系列 | IPC-6012 | 国标更注重环境适应性 |
| 爬电距离 | GB/T 16935.1 | IPC-2221 | 污染等级定义一致 |
| 阻燃 | GB/T 4721 (UL94 等效) | IPC-4101 | 等效 |

### 新手避坑 15 条

1. **电源线不是信号线** —— 1A 最小 12mil (1oz铜厚)，2A 以上用 24mil+
2. **不使用工厂极限值** —— 工厂标 3mil 你就用 6mil
3. **去耦电容必须靠近 IC 引脚** —— ≤5mm，越近越好
4. **IC 每个 VCC/GND 引脚对必须加去耦电容** —— 不可共用
5. **晶振负载电容匹配** —— 查晶振数据手册，不随意选 22pF
6. **BOOT0 必须拉低** —— 忘了就烧不进去程序
7. **NRST 必须上拉** —— 否则 MCU 一直复位
8. **VCAP 电容不能省** —— STM32F1 系列必须加 2.2μF
9. **VDDA 必须供电** —— 即使不用 ADC 也要接 VCC
10. **过孔不要打在焊盘上** —— 除非明确知道是 VIPPO
11. **DRC 设置后必须跑一遍** —— 不要凭肉眼检查
12. **BOM 表 LCSC 编号务必正确** —— 错一个编号整个物料错误
13. **阻焊桥不要信任自动设置** —— 细间距 IC 手动检查
14. **丝印不要覆盖焊盘和测试点** —— 影响可焊性和测试
15. **发板前打印 1:1 纸样验证封装** —— 特别是新封装或手工焊接
