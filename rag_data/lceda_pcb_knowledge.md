## 测控电路设计规范

### 去耦电容放置
- 每个IC的VCC/VDD引脚附近放置0.1μF(X7R)陶瓷电容
- 电容尽量靠近电源引脚，距引脚≤5mm
- 大功率IC（MCU/FPGA/DSP）额外加10μF钽/陶瓷电容
- 模拟电路AVCC与数字VCC分开供电

### 信号完整性
- SPI时钟线远离模拟输入至少5mm
- 差分信号(USB/RS485/CAN)等长匹配，长度差<2mm
- 高频信号线避免90°直角，使用45°拐角或圆弧
- 晶振下方不走其他信号线，晶振负载电容靠近引脚

### 模拟电路布局
- 模拟地与数字地单点连接（磁珠或0Ω电阻）
- 运放输入走线尽量短，远离数字信号
- ADC参考电压引脚加去耦电容(10μF+0.1μF)
- 传感器信号线使用地线包绕（guard trace）

### 电源设计
- 每个电压轨入口加TVS管做ESD保护
- DC-DC输入输出各加电容(输入10-22μF, 输出22-47μF)
- LDO输入输出电容参考数据手册(通常1-10μF)
- 功率地与大信号地分开走，星型接地

## 立创EDA 使用技巧

### BOM 导出
- 菜单 → 制造 → BOM表 → 导出CSV
- 确保所有元件已关联LCSC编号(Cxxxxx)
- 立创商城直接下单需匹配LCSC编号

### 坐标文件导出
- 菜单 → 制造 → 坐标文件 → 导出CSV
- 格式：Designator, Footprint, Mid X, Mid Y, Layer, Rotation
- 单位为mm

### PCB文件格式
- 标准版：文件 → 导出 → EasyEDA JSON (.json)
- 专业版：直接保存 .epro 项目文件(ZIP格式)
- 专业版内部.epcb文件为JSON Lines格式

### 常用快捷键
- W: 布线
- Space: 旋转元件
- G: 调整网格
- Shift+M: 测量距离
- Ctrl+Z: 撤销

## 常见问题排查

### 问题：DRC报"未连接"
原因：布线未完全连接到焊盘中心
解决：重新走线确保终点在焊盘中心捕捉

### 问题：立创下单时封装不匹配
原因：BOM中封装名与LCSC数据库不一致
解决：使用标准封装名，参考LCSC编号对应的推荐封装

### 问题：STM32最小系统不工作
常见原因：
1. BOOT0未拉低（应接10kΩ到GND）
2. NRST未接上拉(10kΩ到VCC)
3. VCAP引脚未接电容(2.2μF到GND，STM32F1系列)
4. VDDA未供电
5. 晶振负载电容不匹配
