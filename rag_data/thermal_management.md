# PCB 热管理设计

> 覆盖 GaN/SiC 功率器件散热、铜镶块技术、嵌入式裸片、液冷等前沿热管理方案。

## 热设计基础

### 热阻模型

结到环境总热阻:
```
RθJA = RθJC (结到壳) + RθCS (壳到散热器) + RθSA (散热器到环境)
```

| 封装 | RθJC (°C/W) | RθJA (°C/W) | 自然散热功率上限 |
|------|------------|------------|----------------|
| SOT-23 | 50-100 | 200-400 | <0.3W |
| SOP-8 | 30-60 | 120-200 | <0.5W |
| QFN-32 (底部焊盘) | 1-5 | 25-50 | <2W |
| TO-252 (DPAK) | 1-3 | 40-60 | <2.5W |
| TO-220 | 0.5-2 | 30-50 | <3W |
| TO-247 (大功率) | 0.2-0.8 | 20-40 | <5W |

### 结温计算

```
Tj = Ta + P × RθJA
```

- Tj = 结温
- Ta = 环境温度
- P = 功耗 (W)

**设计目标**: Tj ≤ 0.8 × Tj_max（留 20% 安全裕量）

### 经验规则

| 功耗 | 散热方案 |
|------|---------|
| <0.5W | 封装自身散热 |
| 0.5-2W | 底部焊盘 + 散热过孔 + 铜皮 |
| 2-5W | 散热器 + 热过孔阵列 |
| 5-20W | 大散热器 + 强制风冷/铜镶块 |
| 20-100W | 铜镶块 + 液冷/热管 |
| >100W | 液冷 + DBC 基板/嵌入式裸片 |

## GaN/SiC 功率器件散热

### 关键挑战
- GaN/SiC 器件开关速度极高 → 功率密度大 → 热通量集中在小的结面积
- SiC 可耐更高温度（>200°C），但周边 PCB 和封装限温
- 热瞬态响应比硅器件快 5-10×，需要低热容散热路径

### GaN 热特性

| 参数 | eGaN FET (EPC) | GaN HEMT (GaN Systems) | Si MOSFET |
|------|---------------|----------------------|-----------|
| RθJC | 0.5-2 °C/W | 0.3-1.5 °C/W | 0.5-3 °C/W |
| Tj_max | 150°C | 175°C | 150°C |
| 封装 | LGA / BGA | 底部冷却 QFN | SO-8 / TO-220 |

### SiC 散热方案

| 方案 | Rth (°C/W) | 成本 | 应用 |
|------|-----------|------|------|
| PCB 铜皮散热 | 5-15 | 低 | <20W |
| 散热器 + 热过孔 | 2-6 | 中 | 20-50W |
| DBC (直接覆铜) 基板 | 0.2-0.5 | 高 | 50-500W |
| 铜镶块 (Copper Coin) | 0.3-0.8 | 中高 | 50-200W |
| 嵌入式裸片 + AlN | 0.2-0.4 | 高 | 100W+ |
| 液冷 | 0.05-0.1 | 最高 | 500W+ |

## 铜镶块 (Copper Coin) PCB 技术

### 原理
在功率半导体裸片下方嵌入厚铜圆柱/块，将热量直接传导到 PCB 背面散热器。

### 关键参数
- 币厚度: 1.5-3.0mm (通用), 最大 5mm
- 币直径: 10-50mm
- 局部热导率: **80-150 W/mK**（对比 FR-4 约 0.3 W/mK）
- 性能: 约为 DBC 的 70-80%，成本为 40-50%
- 老化后热阻增加: **<5%** 超过 10-15 年产品寿命

### 工艺要点
- 铜币通过机械压入或焊接固定在 PCB 腔体中
- 铜币表面需与 PCB 表面齐平（±25μm）以保贴片精度
- 铜币与 PCB 的 CTE 差异需要补偿设计

## 嵌入式功率裸片散热

### PCB 嵌入裸片 (2024-2025 前沿)

将 GaN/SiC 裸片直接嵌入 PCB 结构内：
- 裸片烧结在嵌入的 AlN 陶瓷基板上
- 减少寄生参数：功率回路电感大幅降低，实现更快开关、更少振铃
- **功率密度提高 27%** (500W 48V→12V 降压变换器对比分立 GaN)
- 嵌入式裸片到底表面热阻: **0.2-0.4 °C/W**

### IMS (绝缘金属基板)

铝基板 PCB 结构: 铜箔 → 绝缘介质 → 铝基板
- 绝缘层热阻: ~0.5-2 °C/W (关键瓶颈)
- 铝基板热导率: ~150 W/mK
- 适用于 LED、电源、汽车电子

### DBC (直接覆铜) 基板

- 陶瓷基板 (Al2O3/AlN) 上直接键合铜箔
- AlN DBC 热导率: **170 W/mK**
- 铜厚: 0.2-0.5mm
- 主要用于大功率模块（IGBT/SiC MOSFET）

## 散热过孔设计

### 热过孔阵列设计

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 孔径 | 0.3-0.5mm | 太小影响热传导，太大影响焊接 |
| 间距 | 0.8-1.2mm | 中心到中心 |
| 排列 | 矩形网格 | 覆盖器件散热焊盘下方全部区域 |
| 铜厚 | ≥25μm (孔壁) | 更厚 = 更好的热传导 |
| 填充 | 可选填铜/填树脂 | 填铜散热更好但成本高 |

### 热过孔热阻估算

单个 0.3mm 直径热过孔（1.6mm 板厚, 25μm 孔铜）:
- 单孔热阻: ~80-120 °C/W
- 20 个热过孔阵列: ~4-6 °C/W（热阻并联 + 横向铜皮传导）

## 液冷技术

### 微通道液冷板

| 参数 | 典型值 |
|------|--------|
| 通道宽度 | 0.2-1.0mm |
| 通道深度 | 0.5-2.0mm |
| 热通量 | 100-1000 W/cm² |
| 压降 | 0.5-5 psi |
| COP (制冷系数) | >10,000 |

### 直接 vs 间接液冷

- **间接液冷**: 冷却液不接触芯片（冷板在 PCB 背面），安全性高，热阻稍大
- **直接液冷**: 介电冷却液直接接触芯片/PCB，热阻极低，需密封和冷却液管理
- **浸没式冷却**: 整个 PCB 浸入介电液体中，数据中心主流方案

### 介电冷却液

| 冷却液 | 热导率 (W/mK) | 沸点 (°C) | 适用 |
|--------|------------|---------|------|
| 3M Novec 7100 | 0.069 | 61 | 单相浸没 |
| 3M Novec 7500 | 0.065 | 128 | 高功率浸没 |
| PAO (聚α烯烃) | 0.14 | >250 | 单相 |

## 热仿真方法

### 简化热阻网络法
- 将每个散热路径建模为热阻
- 适合初步估算，精度 ±30%

### CFD (计算流体动力学)
- 工具: Ansys Icepak, Flotherm, SimScale
- 可模拟 3D 流场 + 温度场
- 精度 ±10-15%（校准后可达 ±5%）

### 红外热成像验证
- 板上电后热成像仪实测温度
- 发射率校正: PCB 阻焊发射率 ~0.92-0.95
- 对比仿真与实测，校准模型

## 常见陷阱

### 陷阱一: 散热过孔密度不足
**问题**: 只在 QFN 散热焊盘下放了 4 个热过孔，实测热阻高。**正确**: 热过孔覆盖散热焊盘下方全部面积，孔间距 ≤1.2mm。

### 陷阱二: 忽略铜层横向导热
**问题**: 只关注过孔纵向导热，忽略了铜平面的横向扩散。1oz 铜 (35μm) 横向热阻远低于 FR-4 纵向热阻。**正确**: 利用大面积铜皮做横向热扩散，再经热过孔传导。

### 陷阱三: TIM 热界面材料被低估
**问题**: 散热器直接压在芯片上，无 TIM 或使用低性能导热硅脂。空气隙 (<0.1mm) 热导率仅 0.026 W/mK。**正确**: 使用高性能 TIM（导热系数 ≥3 W/mK），施加适当压力。

### 陷阱四: GaN 器件未考虑热瞬态
**问题**: GaN FET 在脉冲负载下结温瞬间飙升，稳态散热方案来不及响应。**正确**: 靠近 GaN 芯片放置热容大的铜结构（厚铜皮/铜币），缓冲瞬态热冲击。
